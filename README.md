# דיווח יומי - אתרי בנייה

מערכת פשוטה למנהלי עבודה לדווח יומית על עובדי קבלן באתר (חברה, כמות עובדים, שעות), עם דשבורד ניהולי מרוכז.

- **טופס דיווח** (`/`) — עמוד פתוח, נגיש כאפליקציית מסך-בית (PWA), ללא צורך בהתקנה.
- **דשבורד** (`/dashboard`) — מוגן בסיסמה, מציג טבלה וגרפים לפי אתר/תאריך/חברה.
- **אחסון נתונים** — Google Sheets (חינם, כל מנהל עבודה יכול גם לצפות ישירות בגיליון אם תרצה).

## הקמה (חד-פעמית)

### 1. הגיליון (Google Sheets)
1. צור גיליון Google Sheets חדש, למשל "דיווחי אתרים".
2. שים לב ל-ID שלו בכתובת ה-URL: `https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit`

### 2. Apps Script — כתיבת דיווחים
1. בתוך הגיליון: **הרחבות → Apps Script**
2. מחק את התוכן הקיים, הדבק את התוכן של [`google-apps-script.js`](google-apps-script.js)
3. עדכן את `SHEET_ID` בשורה הראשונה
4. שמור, ואז **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. אשר הרשאות, העתק את ה-URL שמתקבל (מסתיים ב-`/exec`) — זה `VITE_APPS_SCRIPT_URL`

### 3. פרסום הגיליון לקריאה (לדשבורד)
1. בגיליון: **קובץ → שתף → פרסם לאינטרנט**
2. בחר את הגיליון "דיווחים", פורמט **CSV**, לחץ פרסם
3. העתק את הקישור — זה `SHEET_URL`

### 4. משתני סביבה ב-Vercel
בהגדרות הפרויקט ב-Vercel → Environment Variables:

| שם | ערך |
|---|---|
| `VITE_APPS_SCRIPT_URL` | ה-URL מסעיף 2 |
| `SHEET_URL` | ה-URL מסעיף 3 |
| `DASHBOARD_PASSWORD` | סיסמה לדשבורד הניהולי |
| `JWT_SECRET` | מחרוזת אקראית ארוכה (אופציונלי, ברירת מחדל = הסיסמה) |

### 5. עדכון רשימת אתרים וחברות
ערוך את [`src/config.js`](src/config.js) — רשימת `SITES` (אתרים פעילים) ו-`CONTRACTOR_COMPANIES` (חברות קבועות להשלמה אוטומטית בטופס). מנהל עבודה יכול גם להקליד חברה שלא ברשימה.

### 6. פריסה
```
npm install
vercel deploy --prod
```
או חיבור ה-repo ל-Vercel דרך ה-UI (import from GitHub).

## שימוש יומיומי

- מנהלי עבודה: שולחים למנהל העבודה קישור לאתר (למשל `https://your-app.vercel.app`), מציעים להוסיף ל"מסך הבית" בטלפון (Add to Home Screen) כדי שירגיש כמו אפליקציה.
- בעל החברה: נכנס ל-`/dashboard` עם הסיסמה, רואה טבלה מסוננת וגרפים לפי אתר/תאריך/חברה.
- כל דיווח נשלח ישירות ל-Google Sheets, ניתן גם לפתוח את הגיליון ישירות אם רוצים לייצא ל-Excel.

## פיתוח מקומי
```
npm install
npm run dev
```
צור קובץ `.env.local` עם `VITE_APPS_SCRIPT_URL=...` כדי שהטופס יעבוד מקומית.
